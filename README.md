# Avenir Toiture Ouest

Website for **Avenir Toiture Ouest**, a roofing and exterior works company based in Brittany, France.

This project is built with **React**, **Vite**, and **Sass**, with a staged launch approach.

---

## Tech stack

- React
- Vite
- Sass (SCSS)
- React Router
